# 東南アジア旅行ガイド — 段階的プロンプト

各ステップのプロンプトを Claude Code に貼り付けて進める。
動作確認してから次のステップへ。

---

## ステップ1: 型定義とシードデータ

lib/countries.ts を作ってください。

Spot（name と description）と Country（slug, name, capital, flag, description, spots, bestSeason）の型定義と、東南アジア10カ国分のシードデータを書いてください。
国は タイ・ベトナム・シンガポール・マレーシア・インドネシア・フィリピン・カンボジア・ミャンマー・ラオス・ブルネイ です。
各国に おすすめスポット3件（name と description）と bestSeason を日本語で入れてください。

---

## ステップ2: DB接続ライブラリ

lib/db.ts を作ってください。

pg の Pool を使って PostgreSQL に接続します。Next.js の HMR でプールが重複しないよう global._pgPool でシングルトン管理してください。
接続先は環境変数（DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD）で設定し、DB_SSL=true のときは rejectUnauthorized: false を付けてください。デフォルトは localhost:5432、DB名 travel_guide、ユーザー/パスワードは postgres です。

以下の3つの関数を実装してください。
- initializeDatabase: countries テーブルを CREATE TABLE IF NOT EXISTS で作り、データが0件なら lib/countries.ts のシードデータを INSERT する
- getCountries: 全件を name 昇順で取得する（best_season カラムは bestSeason にエイリアスする）
- getCountryBySlug: slug で1件取得して返す（見つからなければ null）

countries テーブルのカラムは slug（TEXT, PK）, name, capital, flag, description（TEXT）, spots（JSONB）, best_season（TEXT）です。

---

## ステップ3: 起動時のDB初期化

instrumentation.ts をプロジェクトルートに作ってください。
register() をエクスポートして、NEXT_RUNTIME が nodejs のときだけ lib/db の initializeDatabase() を呼んでください。

あわせて next.config.mjs を更新してください。output を standalone に、experimental.instrumentationHook を true にしてください。

---

## ステップ4: トップページ（国一覧）

components/Header.tsx と components/CountryCard.tsx と app/page.tsx の3ファイルを作ってください。

Header はエメラルドからティールへのグラデーション（from-emerald-600 to-teal-500）の横幅いっぱいのヘッダーで、タイトル「東南アジア旅行ガイド」とサブタイトル「10カ国の観光情報をまとめました」を白文字で表示してください。

CountryCard は Country 型を受け取って /countries/[slug] へのリンクになるカードです。国旗絵文字・国名・首都を表示し、白背景・角丸・影でホバー時に影が強くなるデザインにしてください。

app/page.tsx は先頭に export const dynamic = 'force-dynamic' を付け、getCountries() でデータを取得して Header と CountryCard のグリッド（sm:2列、lg:3列）を表示してください。「全 N カ国を掲載」のテキストとフッター「© 2026 東南アジア旅行ガイド — Built with Next.js 14」も入れてください。

---

## ステップ5: 国詳細ページ

app/countries/[slug]/page.tsx を作ってください。

先頭に export const dynamic = 'force-dynamic' を付けて、params.slug で getCountryBySlug() を呼んでください。見つからなければ notFound() を呼んでください。
generateMetadata で title を「国旗 国名 — 東南アジア旅行ガイド」、description を country.description に設定してください。

ページのレイアウトは以下の構成にしてください。
- ヘッダー：エメラルド〜ティールのグラデーション、国旗・国名・首都を表示、「← 一覧に戻る」リンク付き
- 紹介文：白カード
- ベストシーズン：アンバー系の背景カード
- おすすめスポット：各スポットを白カードで番号付きリスト表示
